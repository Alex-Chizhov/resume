Часть 1. 5 Золотых правил прохождения Live Coding

Решение алгоритмической задачи на собеседовании отличается от написания кода на работе. Интервьюеру важен ваш путь решения, а не только зеленые тесты. Следуйте 5 ключевым шагам:

1. 🗣️ Рассуждайте вслух (Think Aloud)

Никогда не молчите более 15–20 секунд. Если погрузились в мысли, проговорите: «Сейчас я думаю над тем, как снизить сложность с O(N²) до O(N)...».

2. ❓ Задавайте уточняющие вопросы

Выясните границы входных данных: может ли быть пустой массив? Учитывается ли регистр символов? Могут ли быть отрицательные числа? Помещаются ли данные в память?

3. 🐢 Озвучьте брутфорс, затем оптимизируйте

Сначала коротко озвучьте наивное решение в лоб (например, через вложенные циклы за O(N²)), покажите, что задача понята, а затем предложите оптимизацию через хэш-таблицу или два указателя.

4. 🧹 Пишите чистый Pythonic-код

Используйте понятные имена переменных (left, right, seen_map вместо a, b, tmp), придерживайтесь PEP 8 и избегайте спагетти-кода.

📌 Задача 1: Проверка на палиндром (Valid Palindrome)

Easy / Часто встречается

Условие: Дана строка s. Необходимо определить, является ли она палиндромом (читается одинаково слева направо и справа налево), учитывая только буквенно-цифровые символы и игнорируя регистр букв.

Пример 1: s = "A man, a plan, a canal: Panama" → True ("amanaplanacanalpanama")
Пример 2: s = "race a car" → False ("raceacar" != "racecara")

💡 Стратегия на собеседовании:

Наивное решение — отфильтровать строку через генератор списков или isalnum(), привести к нижнему регистру и сравнить с развернутой копией cleaned == cleaned[::-1]. Это требует $O(N)$ по времени и $O(N)$ по памяти под новую строку. Оптимальный путь — использовать паттерн Двух указателей (Two Pointers), движущихся с краев к центру. Это позволит решить задачу за $O(N)$ по времени и $O(1)$ по дополнительной памяти!

🐍 Оптимальное решение на Python:

def is_palindrome(s: str) -> bool:
    """
    Проверяет, является ли строка палиндромом, используя подход двух указателей.
    Временная сложность: O(N) — проходим по строке 1 раз.
    Пространственная сложность: O(1) — не создаем дополнительных строк.
    """
    left = 0
    right = len(s) - 1

    while left < right:
        # Пропускаем символы, не являющиеся буквами или цифрами слева
        while left < right and not s[left].isalnum():
            left += 1
        
        # Пропускаем небуквенно-цифровые символы справа
        while left < right and not s[right].isalnum():
            right -= 1

        # Сравниваем символы в нижнем регистре
        if s[left].lower() != s[right].lower():
            return False

        # Сдвигаем оба указателя к центру
        left += 1
        right -= 1

    return True

# Быстрые тесты для проверки
assert is_palindrome("A man, a plan, a canal: Panama") == True
assert is_palindrome("race a car") == False
assert is_palindrome(" ") == True  # Пустая строка — валидный палиндром
print("✅ Задача 1 успешно прошла тесты!")
⏱️ Время: O(N) (проход по каждому символу не более 2 раз)
💾 Память: O(1) (только переменные указателей)

📌 Задача 2: Проверка на анаграмму (Valid Anagram)

Easy / Часто встречается

Условие: Даны две строки s и t. Напишите функцию, которая возвращает True, если t является анаграммой строки s (состоит из тех же букв в том же количестве), и False в противном случае.

💡 Стратегия на собеседовании:

Первым делом проверьте равенство длин len(s) != len(t). Сортировка обеих строк sorted(s) == sorted(t) занимает $O(N \log N)$ времени. Однако оптимальное решение — подсчет частоты символов через хэш-таблицу (словарь) за $O(N)$ времени.

🐍 Оптимальное решение на Python:

from collections import Counter

def is_anagram(s: str, t: str) -> bool:
    """
    Проверяет, являются ли строки анаграммами через подсчет частот.
    Временная сложность: O(N)
    Пространственная сложность: O(K), где K — количество уникальных символов (<= 26 для латиницы).
    """
    if len(s) != len(t):
        return False

    # Counter(s) создает словарь частот символов {char: count}
    return Counter(s) == Counter(t)

# Альтернативная ручная реализация на словаре (полезно показать интервьюеру)
def is_anagram_manual(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False
        
    counts = {}
    for char in s:
        counts[char] = counts.get(char, 0) + 1
        
    for char in t:
        if char not in counts or counts[char] == 0:
            return False
        counts[char] -= 1
        
    return True

assert is_anagram("anagram", "nagaram") == True
assert is_anagram("rat", "car") == False
print("✅ Задача 2 успешно прошла тесты!")

📌 Задача 3: Сжатие строки (Run-Length Encoding / RLE)

Medium-Easy / Классика

Условие: Напишите функцию для простейшего сжатия строк на основе подсчета подряд идущих повторов символов. Пример: строка aabcccccaaa превращается в a2b1c5a3. Если длина сжатой строки больше или равна длине исходной, вернуть исходную строку.

🐍 Оптимальное решение на Python:

def compress_string(s: str) -> str:
    """
    RLE сжатие строки за один проход.
    Используется список (буфер) для предотвращения O(N^2) конкатенации строк.
    """
    if not s:
        return ""

    compressed = []
    current_char = s[0]
    count = 1

    # Проходим со 2-го символа до конца
    for char in s[1:]:
        if char == current_char:
            count += 1
        else:
            compressed.append(f"{current_char}{count}")
            current_char = char
            count = 1

    # Добавляем последнюю группу символов
    compressed.append(f"{current_char}{count}")

    result = "".join(compressed)
    # Возвращаем сжатую строку только если она реально короче исходной
    return result if len(result) < len(s) else s

assert compress_string("aabcccccaaa") == "a2b1c5a3"
assert compress_string("abc") == "abc"  # "a1b1c1" длиннее чем "abc"
print("✅ Задача 3 успешно прошла тесты!")

📌 Задача 4: Сумма двух чисел (Two Sum)

№1 На Собеседованиях в Мире

Условие: Дан массив целых чисел nums и целевое число target. Напишите функцию, которая возвращает индексы двух чисел из массива таких, что их сумма равна target. Гарантируется, что существует ровно одно решение.

💡 Стратегия на собеседовании:

Двойной вложенный цикл дает $O(N^2)$ по времени. Для оптимизации используем хэш-таблицу (словарь в Python): при проходе по элементу num мы вычисляем разность complement = target - num. Если эта разность уже есть в словаре, мы нашли пару за $O(1)$ на каждый элемент!

🐍 Оптимальное решение на Python:

def two_sum(nums: list[int], target: int) -> list[int]:
    """
    Поиск индексов пары чисел с заданной суммой target за 1 проход.
    Временная сложность: O(N)
    Пространственная сложность: O(N)
    """
    seen = {}  # Словарь вида {число: его_индекс}

    for i, num in enumerate(nums):
        complement = target - num
        # Если разность уже встретилась раньше — возвращаем результат
        if complement in seen:
            return [seen[complement], i]
        # Иначе запоминаем текущее число и его индекс
        seen[num] = i

    return []

assert two_sum([2, 7, 11, 15], 9) == [0, 1]
assert two_sum([3, 2, 4], 6) == [1, 2]
assert two_sum([3, 3], 6) == [0, 1]
print("✅ Задача 4 успешно прошла тесты!")

📌 Задача 5: Поиск единственного числа (Single Number)

Easy / Bit Manipulation

Условие: Дан непустой массив целых чисел nums, в котором каждый элемент встречается ровно дважды, кроме одного элемента, который встречается ровно один раз. Найдите этот элемент. Ограничения: $O(N)$ время и $O(1)$ память!

💡 Стратегия на собеседовании:

Подсчет частот через dict или set требует $O(N)$ дополнительной памяти. Но требование $O(1)$ по памяти идеально решается через **побитовую операцию XOR (исключающее ИЛИ ^)**:

  • a ^ a = 0 (любое число XOR с самим собой дает 0)
  • a ^ 0 = a (число XOR с нулем остается собой)
  • Операция коммутативна: все парные числа взаимно уничтожатся до 0, останется только уникальное число!

🐍 Оптимальное решение на Python:

def single_number(nums: list[int]) -> int:
    """
    Поиск уникального числа с использованием битовой операции XOR.
    Временная сложность: O(N)
    Пространственная сложность: O(1)
    """
    result = 0
    for num in nums:
        result ^= num  # XOR накопление
    return result

assert single_number([2, 2, 1]) == 1
assert single_number([4, 1, 2, 1, 2]) == 4
print("✅ Задача 5 успешно прошла тесты!")

📌 Задача 6: Перемещение нулей в конец (Move Zeroes)

Easy / In-Place

Условие: Дан массив nums. Переместите все нули в конец массива, сохранив относительный порядок ненулевых элементов. Модификация должна происходить in-place без создания копии массива.

🐍 Оптимальное решение на Python:

def move_zeroes(nums: list[int]) -> None:
    """
    Модифицирует список in-place, перемещая нули в конец через 2 указателя.
    Временная сложность: O(N)
    Пространственная сложность: O(1)
    """
    last_non_zero = 0  # Указатель позиции для следующего ненулевого элемента

    for current in range(len(nums)):
        if nums[current] != 0:
            # Меняем местами элементы только при необходимости
            nums[last_non_zero], nums[current] = nums[current], nums[last_non_zero]
            last_non_zero += 1

# Проверка
test_arr = [0, 1, 0, 3, 12]
move_zeroes(test_arr)
assert test_arr == [1, 3, 12, 0, 0]
print("✅ Задача 6 успешно прошла тесты!")

📌 Задача 7: Пересечение двух массивов (Intersection)

Easy / Set Logic

Условие: Даны два массива целых чисел nums1 и nums2. Верните массив их пересечения. Каждый элемент в результате должен быть уникальным.

🐍 Оптимальное решение на Python:

def intersection(nums1: list[int], nums2: list[int]) -> list[int]:
    """
    Пересечение массивов с использованием множств (set).
    Временная сложность: O(N + M)
    Пространственная сложность: O(N + M)
    """
    # Преобразуем оба списка в множества и находим их пересечение через оператор &
    return list(set(nums1) & set(nums2))

assert sorted(intersection([1, 2, 2, 1], [2, 2])) == [2]
assert sorted(intersection([4, 9, 5], [9, 4, 9, 8, 4])) == [4, 9]
print("✅ Задача 7 успешно прошла тесты!")

📌 Задача 8: Максимальная сумма подмассива длины K (Sliding Window)

Medium / Паттерн Sliding Window

Условие: Дан массив чисел nums и целое число k. Найдите максимальную сумму непрерывного подмассива фиксированной длины k.

💡 Стратегия на собеседовании:

Вычисление суммы каждого подмассива с нуля занимает $O(N \cdot K)$ времени. Паттерн Скользящее окно (Sliding Window) позволяет сдвигать окно шириной $K$ вправо за $O(1)$: вычитаем уходящий слева элемент nums[i - k] и прибавляем входящий справа элемент nums[i]!

🐍 Оптимальное решение на Python:

def max_sub_array_of_size_k(nums: list[int], k: int) -> int:
    """
    Поиск макс. суммы подмассива размера K методом скользящего окна.
    Временная сложность: O(N)
    Пространственная сложность: O(1)
    """
    if not nums or k <= 0 or k > len(nums):
        return 0

    # Считаем сумму первого окна размера K
    current_window_sum = sum(nums[:k])
    max_sum = current_window_sum

    # Сдвигаем окно от k-го элемента до конца массива
    for i in range(k, len(nums)):
        current_window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, current_window_sum)

    return max_sum

assert max_sub_array_of_size_k([2, 1, 5, 1, 3, 2], 3) == 9  # Подмассив [5, 1, 3]
assert max_sub_array_of_size_k([2, 3, 4, 1, 5], 2) == 7     # Подмассив [3, 4]
print("✅ Задача 8 успешно прошла тесты!")

📌 Задача 9: Слияние двух отсортированных массивов

Medium / Two Pointers Backwards

Условие: Даны два отсортированных массива nums1 и nums2. Массив nums1 имеет размер $m + n$, где первые $m$ элементов содержат значения, а последние $n$ элементов заполнены нулями. Слейте nums2 в nums1 так, чтобы получился единый отсортированный массив in-place.

🐍 Оптимальное решение на Python:

def merge_sorted_arrays(nums1: list[int], m: int, nums2: list[int], n: int) -> None:
    """
    Слияние с конца (от наибольших элементов к наименьшим).
    Временная сложность: O(m + n)
    Пространственная сложность: O(1)
    """
    p1 = m - 1          # Указатель на последний реальный элемент в nums1
    p2 = n - 1          # Указатель на последний элемент в nums2
    p_write = m + n - 1 # Указатель записи с конца массива nums1

    while p1 >= 0 and p2 >= 0:
        if nums1[p1] > nums2[p2]:
            nums1[p_write] = nums1[p1]
            p1 -= 1
        else:
            nums1[p_write] = nums2[p2]
            p2 -= 1
        p_write -= 1

    # Если в nums2 еще остались элементы — дописываем их
    while p2 >= 0:
        nums1[p_write] = nums2[p2]
        p2 -= 1
        p_write -= 1

# Проверка
arr1 = [1, 2, 3, 0, 0, 0]
merge_sorted_arrays(arr1, 3, [2, 5, 6], 3)
assert arr1 == [1, 2, 2, 3, 5, 6]
print("✅ Задача 9 успешно прошла тесты!")

📌 Задача 10: Валидация скобочной последовательности (Valid Parentheses)

Easy-Medium / Stack

Условие: Дана строка s, содержащая только скобки '(', ')', '{', '}', '[' и ']'. Определите, является ли последовательность правильной (каждая открывающая скобка закрывается соответствующей закрывающей скобкой в правильном порядке).

🐍 Оптимальное решение на Python:

def is_valid_parentheses(s: str) -> bool:
    """
    Проверка скобок через LIFO Стек.
    Временная сложность: O(N)
    Пространственная сложность: O(N)
    """
    stack = []
    # Карта пар: ключ — закрывающая скобка, значение — ожидаемая открывающая
    bracket_map = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in bracket_map:
            # Если попалась закрывающая скобка — достаем верхний элемент из стека
            top_element = stack.pop() if stack else '#'
            if bracket_map[char] != top_element:
                return False
        else:
            # Если открывающая скобка — кладем в стек
            stack.append(char)

    # После обработки всех символов стек должен остаться пустым
    return len(stack) == 0

assert is_valid_parentheses("()") == True
assert is_valid_parentheses("()[]{}") == True
assert is_valid_parentheses("(]") == False
assert is_valid_parentheses("([)]") == False
assert is_valid_parentheses("{[]}") == True
print("✅ Задача 10 успешно прошла тесты!")

Часть 6. Алгоритмы Поиска и Структуры Данных

📌 Задача 11: Бинарный поиск (Binary Search)

Easy / Fundamental O(log N)

Условие: Дан отсортированный по возрастанию массив целых чисел nums и искомое значение target. Напишите функцию поиска target в nums. Если target существует, верните его индекс, иначе верните -1. Сложность: $O(\log N)$.

🐍 Оптимальное решение на Python:

def binary_search(nums: list[int], target: int) -> int:
    """
    Классический итеративный бинарный поиск.
    Временная сложность: O(log N)
    Пространственная сложность: O(1)
    """
    left = 0
    right = len(nums) - 1

    while left <= right:
        # Безопасное вычисление центрального индекса
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1   # Искомый элемент в правой половине
        else:
            right = mid - 1  # Искомый элемент в левой половине

    return -1

assert binary_search([-1, 0, 3, 5, 9, 12], 9) == 4
assert binary_search([-1, 0, 3, 5, 9, 12], 2) == -1

📌 Задача 12: Разворот односвязного списка (Reverse Linked List)

Medium / Linked List Pointer Swapping

Условие: Дан узел head односвязного списка. Разверните список и верните его новый головной узел.

🐍 Оптимальное решение на Python:

class ListNode:
    """Определение узла односвязного списка."""
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode | None) -> ListNode | None:
    """
    Разворачивает односвязный список итеративно.
    Временная сложность: O(N)
    Пространственная сложность: O(1)
    """
    prev = None
    current = head

    while current is not None:
        next_node = current.next  # Сохраняем ссылку на следующий узел
        current.next = prev       # Разворачиваем указатель текущего узла назад
        prev = current            # Сдвигаем prev на текущий узел
        current = next_node       # Переходим к следующему узлу

    return prev  # prev станет новой головой развернутого списка

# Создаем список 1 -> 2 -> 3
node3 = ListNode(3)
node2 = ListNode(2, node3)
node1 = ListNode(1, node2)

# Разворачиваем список
new_head = reverse_list(node1)
assert new_head.val == 3
assert new_head.next.val == 2
assert new_head.next.next.val == 1
assert new_head.next.next.next is None
print("✅ Задача 12 успешно прошла тесты!")

Часть 7. Чек-лист проверки кода перед отправкой на собеседовании

🚀 Ручной прогон (Dry Run) за 60 секунд:

  1. Пустой ввод и None: Что произойдет, если на вход пришел [], "" или None? Будет ли IndexError?
  2. Массив из 1 элемента: Корректно ли отрабатывают циклы while left < right или range(1, len(nums))?
  3. Дубликаты: Не ломается ли логика при одинаковых элементах в массиве?
  4. Указатели границы массива: Проверьте условия left <= right и mid = left + (right - left) // 2.
  5. Сложность O(T) и O(M): Готовы ли вы обосновать, почему выбрали именно эту структуру данных?

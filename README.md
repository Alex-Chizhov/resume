**QAlify** (доступен по адресу **[https://qalify.ru/](https://qalify.ru/)**) — это современный инженерный блог и практическая база знаний для QA-инженеров, специалистов по автоматизации тестирования (SDET) и архитектуре обеспечения качества.

---

## 📌 Ключевые темы и материалы

Блог содержит фундаментальные гайды, практические разборы и готовые паттерны автотестирования:

* 🐍 **Python & PyTest**:
  * [Фикстуры в PyTest: от новичка до профессионала](https://qalify.ru/#/article/pytest-fixtures-best-practices) — скоупы, `yield`-очистка, параметризация, фабрики и `conftest.py`.
  * [Паттерны проектирования в автоматизации](https://qalify.ru/#/article/qa-design-patterns-python) — Page Object, Page Element, Singleton, Builder, Facade, Screenplay.
  * [Live Coding и алгоритмы на собеседовании](https://qalify.ru/#/article/python-interview-algorithms) — 12 задач с разбором Big O и решениями.
* 🌐 **API & Микросервисы**:
  * [Тестирование gRPC сервисов](https://qalify.ru/#/article/grpc-testing-guide) — Protobuf, HTTP/2, PyTest стабы, моки gRPC-сервера и нагрузка через `ghz`.
  * [Виды и тестирование авторизации](https://qalify.ru/#/article/authorization-testing-guide) — Basic Auth, JWT, OAuth 2.0, RBAC, ABAC, BOLA/IDOR.
* 🐳 **DevOps & Инфраструктура**:
  * [Docker для QA-инженеров](https://qalify.ru/#/article/docker-for-qa-engineers) — Docker Compose, FastAPI, PyTest, Allure и деплой в CI/CD.
  * [Linux для QA-инженера](https://qalify.ru/#/article/linux-for-qa-engineers) — 50+ консольных команд, разбор логов (`journalctl`, `jq`) и сетевая диагностика (`curl`, `tcpdump`).
* 🤖 **ИИ & Инструменты**:
  * [ИИ в тестировании ПО 2026](https://qalify.ru/#/article/ai-in-software-testing-2026) — генеративные модели (DeepSeek, Qwen, Claude, Mistral) в повседневных задачах QA.
  * [Playwright vs Selenium](https://qalify.ru/#/article/playwright-vs-selenium) — архитектурное сравнение двух гигантов E2E-автоматизации.

## ⚡ Особенности платформы

* **🚀 Высокая скорость работы**: Клиентская маршрутизация на чистом JavaScript без тяжелых сторонних фреймворков.
* **🔍 Мгновенный поиск**: Интерактивный поиск по названию, тегам и категориям статей с поддержкой хоткея (`Ctrl+K` / `Cmd+K`).
* **🎨 Сочный UI/UX**: Тёмная тема в стиле Cyberpunk/IDE, анимационный эффект частиц Plexus на Canvas и подсветка синтаксиса Tokyo Night.
* **📱 Адаптивность**: Полноценная поддержка мобильных устройств и планшетов.

## 🛠 Технологический стек

* **Frontend**: HTML5, Vanilla CSS3 (Custom Variables, CSS Grid, Flexbox), JavaScript (ES6+ Async/Await).
* **Highlighter**: Highlight.js (Tokyo Night Dark theme).
* **Hosting & Domain**: GitHub Pages + Custom Domain (`qalify.ru` via CNAME).
